# Rollback evidence checklist

This file is a checklist/template, not fabricated evidence. Perform the steps in README.md and take real screenshots from your terminal.

- [ ] Initial project commit visible in `git log --oneline`
- [ ] Small documentation update committed
- [ ] `git revert HEAD` completed successfully
- [ ] `git log --oneline -3` shows both the update and revert commits
- [ ] `git status` reports a clean working tree

Record the commit IDs and paste your screenshots into the internship submission portal. Do not claim rollback evidence until you have performed the commands.
